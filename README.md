# Student Registration & Contact Intelligence System

## 1. Introduction
The Student Registration & Contact Intelligence System is a Python-based application designed to manage student contact information. It validates student details, identifies invalid and duplicate records, and stores valid records in a CSV file.

## 2. Objectives
- To validate student names, phone numbers and email addresses.
- To identify duplicate contact details.
- To store valid student records using CSV file handling.
- To provide options to register, search, update and delete student records.
- To generate analytical reports.

## 3. Technologies Used
- Programming Language: Python
- Concepts: Variables, Strings, Lists, Dictionaries, Functions, Sets and File Handling.
- Module: CSV

## 4. Project Modules
- validator.py – Validates names, phone numbers and email addresses.
- loader.py – Reads CSV records and separates valid and invalid records.
- analytics.py – Generates statistical reports.
- main.py – Provides the main menu and student management operations.
- contacts.csv – Contains sample student contact records.
- students_clean.csv – Stores validated student records.

## 5. Features
1. View all student records.
2. Search by name, phone number or email.
3. Register a new student.
4. Update student details.
5. Delete student records.
6. View analytical reports.

## 6. Conclusion
This project demonstrates how Python can be used to manage and validate student contact information. It provides practical experience with functions, lists, dictionaries, sets and CSV file handling.
